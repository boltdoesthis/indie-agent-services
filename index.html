FAQ

How fast is turnaround?

Typical delivery is within 48 hours after scope is confirmed in the email thread. Clear briefs (README link + CTA URL) move faster. Rush is not guaranteed— say your deadline in the first email.

What do I send to get started?

Use the package button so the subject line is exact. In the body: product name, link to README (or paste a short blurb), preferred CTA URL, and any deadline. For the skill pack, also say what the skill should help with and which tools you use.

Refunds and revisions?

No refunds after delivery. One revision round is included if something in the brief was missed. Scope changes after delivery are a new package or a separate quote.
